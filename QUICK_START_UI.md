## 🎨 Color Legend

Throughout the UI, colors have meaning:

### Risk Levels
- 🟢 **Green** = Low Risk (safe to use)
- 🟡 **Orange** = Medium Risk (monitor closely)
- 🔴 **Red** = High Risk (consider alternatives)

### UI Elements
- 🔵 **Blue** = Accent color (buttons, links, winners)
- ⚫ **Dark Gray** = Background
- ⚪ **White** = Primary text
- 🌫️ **Light Gray** = Secondary text

### Status Indicators
- ✅ **BEST** badge = Winner in comparison
- 📊 Numbers in **blue** = Good performance
- 📉 Numbers in **red** = Poor performance

## 💡 Pro Tips

### Tip 1: Combine Filters
```
Use multiple filters together:
Category + Risk + Location + Min On-Time
= Very specific supplier search
```

### Tip 2: Use Semantic Search
```
In "Find Suppliers" tab, describe what you need:
"reliable cold chain logistics with fast delivery"
Better than: "logistics company"
```

### Tip 3: Compare Before Deciding
```
Never pick a supplier without comparing:
```

## 🐛 Troubleshooting

### Images Not Loading?
```
Problem: Product images show gray boxes
Solution: Check internet connection (images from Unsplash)
Backup: Images will show fallback placeholder
```

### Filters Not Working?
```
Problem: Selections don't filter table
Solution: Hard refresh page (Ctrl+Shift+R)
Check: Console for JavaScript errors (F12)
```

### Excel Won't Download?
```
Problem: Download button doesn't work
Solution: Check popup blocker
Try: Right-click button → "Save link as..."
```

### Comparison Shows Error?
```
Problem: "Supplier not found"
Solution: Ensure supplier names exactly match
Check: Spelling and capitalization
```

### Page Loads Slowly?
```
Problem: Takes >5 seconds to load
Solution: Clear browser cache
Check: Server is running (port 8000)
Verify: No other apps using port 8000
```
