STEP 1: CREATE REPOSITORY ON GITHUB
────────────────────────────────────────────────────────────
1. Open browser: https://github.com/new
2. Fill in:
   - Repository name: Nexora  (or SupplyWise-Procurement)
   - Description: AI-powered procurement intelligence platform
   - Visibility: Public (or Private)
   - ❌ DO NOT check "Add a README file"
   - ❌ DO NOT add .gitignore
   - ❌ DO NOT choose a license
3. Click: "Create repository"

STEP 2: COPY YOUR REPOSITORY URL
────────────────────────────────────────────────────────────
After creating, GitHub will show your repo URL:
https://github.com/YOUR_USERNAME/Nexora.git

Copy this URL!


STEP 3: UPDATE GIT REMOTE (RUN THESE COMMANDS)
────────────────────────────────────────────────────────────
Open PowerShell in this folder and run:

# Remove old remote
git remote remove origin

# Add YOUR repository (replace YOUR_USERNAME)
git remote add origin https://github.com/YOUR_USERNAME/Nexora.git

# Verify it's set correctly
git remote -v


STEP 4: PUSH TO YOUR REPOSITORY
────────────────────────────────────────────────────────────
# Push all commits
git push -u origin main

# You may be asked for credentials:
# Username: YOUR_GITHUB_USERNAME
# Password: YOUR_GITHUB_PASSWORD (or Personal Access Token)


STEP 5: VERIFY ON GITHUB
────────────────────────────────────────────────────────────
Open your repository in browser:
https://github.com/YOUR_USERNAME/Nexora

You should see:
✅ 47 files
✅ README.md displayed
✅ All folders (app, backend, data, etc.)
✅ Your commit message


═══════════════════════════════════════════════════════════
                    🔐 IF AUTHENTICATION FAILS
═══════════════════════════════════════════════════════════

GitHub no longer accepts passwords for git operations.
You need a Personal Access Token:

1. Go to: https://github.com/settings/tokens
2. Click: "Generate new token (classic)"
3. Name: "Nexora Push"
4. Scopes: Check ☑ repo
5. Click: "Generate token"
6. COPY THE TOKEN (you won't see it again!)

When pushing:
Username: YOUR_USERNAME
Password: PASTE_YOUR_TOKEN_HERE
